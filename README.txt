Publish with GitHub Pages:
1. Create a GitHub repository (for example, taelon-portfolio).
2. Upload all files in this folder into the repository root. Keep filenames unchanged.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Open the GitHub Pages URL and test all project/PDF links.
